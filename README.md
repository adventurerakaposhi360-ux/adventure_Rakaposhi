# Adventure Rakaposhi - Premier Tourism, Treks & Mountaineering Expeditions

High-end, responsive tourism web platform for Gilgit-Baltistan, Pakistan.

## Deployment Instructions

This folder is the whole site: `index.html`, `style.css`, `app.js`, and `images/`. It is a static site, so GitHub and Vercel do not need a build command.

`images/archive/` stays on your computer only. It holds unused photos and a zip that is too large for GitHub.

### GitHub, then Vercel

1. In this folder, commit the site and push it to a new GitHub repository.
2. In Vercel, choose **Add New Project** and import that repository.
3. Framework preset: **Other**.
4. Leave Build Command and Output Directory empty. The site root is this folder.
5. Deploy. Vercel serves `index.html`, and `/experiences` and `/gallery` open their pages.

### Other hosts

1. **Netlify**:
   - Drag and drop this folder directly into [app.netlify.com/drop](https://app.netlify.com/drop).
   - Your site is live instantly with an SSL certificate.

2. **GitHub Pages**:
   - Push this codebase to a GitHub repository.
   - Go to `Settings > Pages`, select `Branch: main`, folder `/ (root)`, and click **Save**.

3. **cPanel / Apache / Nginx / Shared Hosting**:
   - Upload all files (`index.html`, `style.css`, `app.js`, and `images/`) into your `public_html/` or document root folder.
